# 006IDC 社区协作模板

006IDC 账号的社区协作模板仓库，供公开项目复用问题反馈、Pull Request、行为准则、治理和安全报告约定。

## 模板入口

- [问题反馈](.github/ISSUE_TEMPLATE/bug_report.yml)与[功能建议](.github/ISSUE_TEMPLATE/feature_request.yml)
- [Pull Request 模板](.github/PULL_REQUEST_TEMPLATE.md)
- [行为准则](CODE_OF_CONDUCT.md)、[治理说明](GOVERNANCE.md)与[安全报告](SECURITY.md)

这些文件供项目复用，同名文件以具体项目为准；具体启用方式需核对目标仓库设置和平台支持，不保证自动应用到账号下所有项目。

由[零零陆云计算（006IDC）](https://github.com/006IDC)维护。具体产品的安装、版本和许可请查看对应仓库。
